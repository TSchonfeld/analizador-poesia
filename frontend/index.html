Este servidor no tiene una API key de IA: se analizan la métrica, la versificación y los recursos formales que se detectan por reglas. Para sumar metáforas, temas e interpretación alcanza con una key gratuita de Gemini (ver el README).

La métrica y la versificación se calculan con reglas deterministas; los recursos, temas e interpretación los propone un modelo de lenguaje (o, sin IA, un conjunto de reglas) y conviene revisarlos.
